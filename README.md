# Healthcare Census Application

A practice project developed as part of the **IBM Full-Stack JavaScript Developer Professional Certificate** on Coursera.

This application demonstrates the design and implementation of a structured HTML form for collecting diverse user information relevant to a healthcare census context. It utilizes JavaScript to manage form submission, capture input values, handle events, and dynamically display user-provided feedback on the webpage.

## Project Overview

The application enables users to submit personal and feedback-related data through a well-structured form. Key functionalities include:

- Collection of user details such as name, age, email, and job information
- Capture of product or service feedback
- Client-side form validation and submission handling
- Dynamic rendering of submitted data on the page without a full page reload
- Event-driven interactions using JavaScript

This project focuses on foundational front-end skills, emphasizing form design, DOM manipulation, and event handling.

## Technologies Used

- **HTML5** – Semantic structure and form elements
- **CSS3** – Styling and responsive layout
- **JavaScript (Vanilla)** – Form handling, event listeners, input capture, and dynamic content display

## Features

- Structured multi-field form for healthcare-related census data
- Capture of user inputs on form submission
- Dynamic display of submitted feedback
- Event handling for form submission and user interactions
- Clear separation of structure (HTML), presentation (CSS), and behavior (JavaScript)

## Getting Started

### Prerequisites

- A modern web browser (Chrome, Firefox, Edge, or Safari)

### Running the Application

1. Clone the repository:
   ```bash
   git clone https://github.com/greattitandev/health_census.git
   ```
2. Navigate to the project directory:
   ```bash
   cd health_census
   ```
3. Open `index.html` directly in your browser, or serve the files using a local server:
   ```bash
   # Using Python (example)
   python -m http.server 8000
   ```
   Then visit `http://localhost:8000`.
